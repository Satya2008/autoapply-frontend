# AutoApply AI - Frontend

React dashboard for AutoApply AI platform.

## Tech Stack
- React 18
- Vite
- Tailwind CSS
- Axios
- React Router v6
- Recharts (analytics)

## Setup
```bash
npm install
npm run dev
```

## Pages
- `/login` - Login/Register
- `/dashboard` - Job listings + match scores  
- `/profile` - User profile & skills
- `/applications` - Applied jobs tracker
- `/settings` - Auto apply settings
